# Kişisel Web Sitesi

Mertcan Kılınç'ın kişisel portfolyo sitesi.

**🔗 Canlı site: [klncmertcan.github.io/personal_website](https://klncmertcan.github.io/personal_website/)**

## İçerik

Hakkımda, eğitim, beceriler, projeler, gönüllülük ve iletişim bölümlerinden oluşan tek sayfalık bir site. CV'ye hero bölümündeki indirme butonundan ulaşılabilir.

## Teknolojiler

HTML, CSS, JavaScript — herhangi bir framework veya bağımlılık kullanılmadı. GitHub Pages üzerinde barındırılıyor.

## Dosya yapısı

```
index.html      Sayfa yapısı ve içerik
style.css       Stiller (koyu tema, nötr gri palet)
script.js       Scroll animasyonları ve aktif menü takibi
cv.pdf          İndirilebilir CV
photo.jpeg      Profil fotoğrafı
favicon.svg     Site ikonu
```
